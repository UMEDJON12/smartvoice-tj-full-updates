# SmartVoice TJ Full

Выпуски Full со встроенными Milena Full, Yuri Full и резервным Milena Compact.

Это отдельный репозиторий Full. Обычная SmartVoice TJ использует smartvoice-tj-updates.

## Установка

В разделе Releases скачайте файл .apk. Для перехода на этот репозиторий установите Full 5.2.34 или новее поверх прежней Full. Сохранены пакет приложения и подпись.

## Публикация владельцем

Подготовленные выпуски остаются черновиками. Проверьте APK на телефоне, затем откройте Edit → Publish release. В этом репозитории Full можно назначать Latest.

После публикации процедура publish-full-update-channel проверяет публичный APK, подпись, пакет, версию и SHA-256. Только после проверки обновляется updates/full.json. До первой публичной публикации канал отсутствует; черновики пользователям не предлагаются.

Полные исходники, инструкция и результаты проверок прилагаются к каждому выпуску. Закрытые ключи подписи в репозиторий не загружаются.
